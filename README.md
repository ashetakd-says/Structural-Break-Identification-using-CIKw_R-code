# CIKw-GLRT Binary Segmentation

This repository contains the R code for implementing the proposed **CIKw-GLRT Binary Segmentation procedure** and reproducing the numerical results reported in the manuscript.

The computational workflow is organized across **multiple R scripts**, with separate files for CIKw data generation, PSO-based parameter estimation, GLRT and parametric bootstrap calibration, Binary Segmentation, BIC/MIC model selection, simulation studies, performance evaluation, graphical outputs, and the **India Revenue data analysis**.

### Software

* R / RStudio
* Windows 11 (64-bit)

### Required R Packages

`pso`, `numDeriv`, `tidyverse`, `readr`, `ggthemes`, `scales`, `patchwork`

The individual R scripts are provided in the repository and can be run according to their respective computational components.
